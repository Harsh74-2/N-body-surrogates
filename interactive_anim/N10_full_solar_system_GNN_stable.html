N=10 — Full Solar System — GNN_stable

Solid coloured markers = surrogate prediction (GNN_stable); open grey markers = closed-form reference; dashed grey lines = full reference paths; faint solid lines = full predicted paths. Each frame is one rollout step (dt = yr). Positions are primary-centred, in AU. The full paths are Catmull-Rom spline-smoothed for display only (checkbox above); the markers always show the exact dumped frames, and the smooth curve passes through every dumped point. Hover a body for coordinates. Drag the slider to scrub; buttons play/pause; the select sets playback speed. A pre-rendered mp4 of the same rollout is also available.
