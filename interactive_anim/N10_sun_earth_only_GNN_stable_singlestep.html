N=10 — Sun Earth Only — GNN_stable (single-step)

Solid coloured markers = surrogate prediction (GNN_stable); open grey markers = reference trajectory (leapfrog / closed-form); dashed grey lines = full reference paths; faint solid lines = full predicted paths. Each frame is one reference-warm-up single step (dt = yr). Positions are primary-centred, in AU. The full paths are Catmull-Rom spline-smoothed for display only (checkbox above); the markers always show the exact dumped frames, and the smooth curve passes through every dumped point. Hover a body for coordinates. Drag the slider to scrub; buttons play/pause; the select sets playback speed. This viewer shows the single-step evaluation: each frame is one independent next-frame prediction from a warm-up window that is re-built from the reference every frame, so errors do not compound.
