Interactive trajectory viewers

Rollout viewers (first table per body count): animated, scrub-able comparison of the autoregressive surrogate rollout against the reference for every body-count, preset, and architecture. Each viewer plays the same rollout as the corresponding mp4 clip, with play/pause, speed, plane selection (X–Y / X–Z / Y–Z), hovering coordinates, and a frame scrubber.

Single-step viewers (second table per body count, suffixed singlestep): the single-step evaluation — every frame is one independent next-frame prediction from a warm-up window that is re-built from the reference each frame, so errors do not compound. The same styling applies: solid coloured markers = prediction, open grey markers + dashed grey lines = reference.
